# 启动

在项目根目录操作。

1. 建库。库名和 `.env` 里的 `APP_DB_NAME` 一致，默认是 `base_app`。

```sql
CREATE DATABASE base_app DEFAULT CHARSET utf8mb4;
```

表可以手工执行 `ddl/001_rbac.sql`，也可以不执行。应用启动时会按模型建表，并写入管理员账号。

2. 准备环境变量。

```text
copy .env.example .env
```

至少改 `APP_DB_PASSWORD`。变量说明见 [环境变量](环境变量.md)。

3. 安装依赖。

```text
pip install -e .
```

4. 启动。

```text
python -m app.main
```

浏览器打开 http://127.0.0.1:8000/docs 。

本机演示账号是 `admin` / `admin123`。这是开发账号，上线前改掉密码，并设置 `APP_SECRET_KEY`。
