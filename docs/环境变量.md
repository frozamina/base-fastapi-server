# 环境变量

复制 `.env.example` 为 `.env`。已经存在于系统环境里的变量优先，空值不会覆盖代码里的开发默认。

| 变量 | 作用 | 不填时 |
|---|---|---|
| `APP_DATABASE_URL` | 完整 SQLAlchemy 连接串。填了就不再看下面的分项 | 用分项拼接 |
| `APP_DB_USER` | MySQL 用户 | `root` |
| `APP_DB_PASSWORD` | MySQL 密码 | 本地开发默认 `123456` |
| `APP_DB_HOST` | 主机 | `localhost` |
| `APP_DB_PORT` | 端口 | `3306` |
| `APP_DB_NAME` | 库名 | `base_app` |
| `APP_SECRET_KEY` | JWT 签名密钥 | 仅供开发的固定值 |

生产环境必须设置 `APP_SECRET_KEY` 和数据库密码，不要依赖代码里的默认值。

连接串示例：

```text
APP_DATABASE_URL=mysql+pymysql://root:密码@localhost:3306/base_app?charset=utf8mb4
```
